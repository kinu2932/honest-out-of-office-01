One brutally honest but still polite out-of-office auto-reply, written by
`main.py` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

The reply stacks three honest admissions inside one polite frame — not
checking the inbox while away, the mountain waiting on return, and the
non-urgent mail quietly retiring — so it reads as one sentence a manager
would let stand, and a reader would quote.

## Entry

> Thank you for your email — I'm away until Monday and honestly not checking my inbox, which will be a mountain when I return, so I'll answer the urgent ones first and let the rest retire quietly.

194 characters, one sentence, no trailing newline.

## Run

```sh
python3 main.py
```
